# 🏛️ 키아노스 마켓 펄스 (KYANOS Market Pulse)
> **초경량 실시간 금융·암호화폐 인텔리전스 모니터링 시스템**

키아노스 제국 금융 센터의 실시간 시세 모니터링 프로그램입니다.
**API 키 발급 불필요**, **추가 라이브러리 설치 불필요**, **평생 100% 무료(0원)** 로 실시간 시세를 추적합니다.

---

## 📌 주요 특징
1. **무과금 & 독립성**: 업비트, 네이버 증권, 야후 파이낸스의 무료 공개 REST 엔드포인트를 직접 연동하여 과금이나 인증 만료 없이 영구 구동됩니다.
2. **초경량 & 무설치**: 파이썬 기본 표준 라이브러리(`urllib`, `json`, `http.server`)만으로 제작되어 추가 `pip install` 없이 바로 실행됩니다.
3. **2가지 실행 모드**:
   - **웹 대시보드 (`monitor_web.py`)**: 세련된 다크 테마(Cyber FinTech) UI, 4초 자동 갱신 및 시세 변동 플래시 효과.
   - **콘솔 모드 (`monitor_console.py`)**: 터미널 환경에서 깔끔한 ANSI 컬러(상승 빨강, 하락 파랑)로 실시간 조회.

---

## 🚀 실행 방법 (원클릭)

탐색기에서 아래 배치 파일을 더블 클릭하여 즉시 실행할 수 있습니다:

1. **웹 대시보드 실행**: `웹대시보드_실행.bat` 더블 클릭
   - 자동으로 브라우저(`http://localhost:8899`)가 열리며 4초 주기로 실시간 갱신됩니다.
2. **콘솔 모드 실행**: `콘솔모니터_실행.bat` 더블 클릭
   - 검은색 터미널 창에서 5초마다 깜빡임 없이 깔끔하게 시세표가 갱신됩니다.
