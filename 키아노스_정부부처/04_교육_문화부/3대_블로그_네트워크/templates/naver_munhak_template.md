# 『파이튼의 문학산책』 네이버 원고 규격

> 네이버 스마트에디터는 **평문으로 붙여넣은 뒤 에디터에서 서식을 입히는 방식**이 가장 깨끗합니다.
> `블로그_원고_정화실.html`에서 **[네이버 문학산책]**을 고르면 이 규격대로 평문이 만들어집니다.

---

## 원고 구성

```
[제목] 작품명 — 부제 (검색에 걸릴 핵심어 1개 포함, 30자 이내)

[카테고리] 사색의 창 / 어떤 인생의 일대기 / 시선의 화첩 / 인생의 명곡 / 동서양의 지혜 / 길 위의 사진첩
[연재 번호] (일대기·명곡 연재일 때) 예: 어떤 인생의 일대기 ⑫

(대표 이미지 1장 — 직접 찍은 사진 우선)

본문 첫 문단: 3~4문장, 글의 정서와 주제를 바로 드러냄.

본문: 문단은 4~6문장, 문단 사이 한 줄 띄움.
      인용구는 에디터의 '인용구' 서식 사용.
      소제목이 필요하면 에디터의 '소제목' 서식 사용.

맺음 구절: 여운을 남기는 한 문장.

─────────────
글·사진 파이튼 | 『파이튼의 문학산책』
#태그1 #태그2 #태그3 (5~10개: 작품 갈래·주제·인물·장소)
```

## 체크리스트

- [ ] 원작 전문은 네이버에만 싣는다 (구글 『예술세계』에는 발췌·해설판만)
- [ ] HWP에서 바로 복사하지 않고 정화실을 거쳤다
- [ ] 대표 이미지는 직접 찍은 사진 또는 앤트 제작 이미지 (저작권 확인)
- [ ] 연재물은 회차 번호와 이전 회 링크를 붙였다
- [ ] 태그 5~10개
