## 🌿 7대 지혜의 숲 핵심 요약

| 지혜의 숲 테마 | 손자병법 핵심 명구 | 삶의 실천적 지혜 |
| :--- | :--- | :--- |
| **1. 생존의 숲** | `선위불가승 이대적지가지 (先爲不可勝 以待敵之可勝)` | 남을 이기려 조급해하기 전에 내가 먼저 무너지지 않는 실력과 루틴, 내면의 방파제를 구축하라. |
| **2. 관계의 숲** | `부전이굴인지병 선지선자야 (不戰而屈人之兵 善之善者也)` | 상대를 힘으로 짓밟지 말고, 명분을 살려주며 상생의 제3의 길을 열어 싸움 자체를 없애라. |
| **3. 시간의 숲** | `병귀승 불귀구 (兵貴勝 不貴久) / 교구(巧久)보다 졸속(拙速)` | 완벽한 준비를 핑계로 결정을 미루지 말고 신속히 매듭지으며, 과거의 상처에 매달리는 감정 소모전을 즉시 끝내라. |
| **4. 유연의 숲** | `병형상수 (兵形象水) / 피실격허 (避實擊虛)` | 고정관념과 아집을 깨고 물처럼 유연하게 변화에 적응하며, 남들이 몰려가는 길을 피해 빈 곳을 개척하라. |
| **5. 절제의 숲** | `주불가이노이흥사 장불가이온이치전 (主不可以怒而興師)` | 순간의 분노와 상처받은 자존심으로 인생의 칼을 뽑지 마라. 화가 치밀 때는 입을 닫고 하룻밤을 삭혀라. |
| **6. 통찰의 숲** | `지피지기 백전불태 (知彼知己 百戰不殆) / 선지 (先知)` | 짐작이나 소문에 의존하지 말고, 자신의 한계와 상대의 실체를 냉혹할 만큼 객관적인 사실과 데이터로 직시하라. |
| **7. 기세의 숲** | `격수지지 지어표석자 세야 (激水之疾 至於漂石者 勢也)` | 억지 노력으로 발버둥 치지 말고, 평소에 실력(正)을 연마하다가 결정적인 시대의 파도와 흐름(勢)을 타라. |
