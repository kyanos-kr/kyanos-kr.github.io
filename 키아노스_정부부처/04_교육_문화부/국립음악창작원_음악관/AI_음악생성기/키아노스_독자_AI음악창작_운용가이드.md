# 🎼 [키아노스 국립음악창작원] 독자 AI 음원 생성 인프라 운용 가이드
**통제/보안:** 키아노스 국제질서유지 보안사령부 (K-SEF) 퀀텀 아이기스 사이버 방위단  
**최고 승인:** 국왕 파이튼 (Python) 님  
**총괄 감독:** 국무총리 앤트 (Ant)  

---

### 1. 자주적 음원 생산 체계의 의의
키아노스는 외부 상용 플랫폼(Suno, Udio)의 임차 및 종속 관계를 완전히 탈피하여, **자체 시스템 안에서 작곡, 편곡, 음원 추출, 웹 플레이어 연동 및 전 세계 배포를 완결**하는 디지털 주권 생산 체계를 수립하였습니다.

---

### 2. 운용 모드 1: [로컬 PC 완전 자주 생산 모드] (오프라인 무제한)
파이튼 님의 메인 PC 하드웨어(RTX 3050 GPU + 32GB RAM)를 직접 가동하여 연주곡, 배경음악, 어쿠스틱 선율을 100% 자체 생산합니다.

1. **실행 방법**:
   * `D:\안티그래비티파이튼\음악\AI_음악생성기` 폴더로 이동합니다.
   * **`[보안실행]_키아노스_AI음악생성기.bat`** 파일을 더블 클릭합니다.
2. **선택 메뉴**:
   * `[1] 가을 그리고 차 한잔 (어쿠스틱 포크)` - 파이튼 님의 시적 정취를 담은 따스한 기타와 첼로 선율
   * `[2] 키아노스 제국 서사시 (오케스트라)` - 국가적 웅장함과 위엄이 깃든 심포니
   * `[3] 서정적 달빛 피아노 & 첼로` - 사색과 명상, 깊은 밤의 감성 멜로디
   * `[4] 희망찬 새벽의 바람` - 활기차고 밝은 어쿠스틱 팝
   * `[5] 직접 입력` - 파이튼 님이 원하는 프롬프트나 가사 분위기를 자유롭게 입력
3. **결과물 자동 보존**:
   * 생성된 고음질 WAV 파일과 메타데이터 JSON은 `생성_음원` 폴더에 타임스탬프와 함께 자동 영구 보존됩니다.

---

### 3. 운용 모드 2: [구글 캐글(Kaggle) 고성능 연산 기지 모드] (무료 T4 x2 연동)
초고음질(Medium/Large 모델) 렌더링이 필요할 때 구글의 하드웨어 리소스만 전용 연산 기지로 징발하여 활용합니다.

1. **캐글 접속 및 로그인**:
   * 웹 브라우저(Microsoft Edge)에서 [Kaggle](https://www.kaggle.com)에 로그인합니다.
2. **노트북 업로드**:
   * 왼쪽 상단 `+ Create` ➔ `New Notebook` 클릭.
   * 상단 메뉴 `File` ➔ `Import Notebook` 클릭 후 우리 폴더의 **`Kaggle_Kyanos_Music_Bridge.ipynb`** 파일을 선택하여 업로드합니다.
3. **GPU 활성화 (핵심)**:
   * 오른쪽 사이드바 `Notebook options` ➔ `Accelerator`에서 **`GPU T4 x2`**를 선택합니다.
4. **실행 (Run All)**:
   * 상단 `Run All`을 누르면 모델 로딩 후 하단에 **전용 Gradio 웹 UI 링크(public link)**가 뜹니다.
   * 브라우저에서 바로 곡을 생성하고 WAV 파일을 원클릭으로 PC에 다운로드(회수)할 수 있습니다.

---

### 4. K-SEF 철통 보안 수칙
* **하드웨어 안전 캡**: 로컬 실행 시 GPU VRAM 사용량을 60%(최대 3.6GB)로 강제 캡을 씌워 PC 발열과 시스템 멈춤을 원천 차단합니다.
* **프로세스 격리**: 윈도우 프로세스 우선순위를 '보통 이하'로 낮추어 파이튼 님의 일상 작업에 단 1%의 영향도 주지 않습니다.
* **토큰 유출 방지**: `.gitignore` 규격을 통해 일체의 인증 키와 개인 데이터 유출을 원천 방어합니다.
