# [편곡] 5월의 사랑 (May Love)
**원작 시·가사: 파이튼 (Python)** — 원문 그대로 사용 (가사 수정 없음)
**편곡·코드 설계: 앤트 (Ant)**

---

## 1. 곡 개요

* **장르**: 브라이트 어쿠스틱 포크 팝 (Bright Acoustic Folk-Pop)
* **박자 / 템포**: 4/4 / 96 BPM (산책하듯 설레는 미디엄 템포)
* **조 (Key)**: **C Major** (밝고 맑은 5월의 햇살 느낌. 개방현 위주라 초보도 연주 쉬움)
* **악기**: 어쿠스틱 기타(주 리듬), 가벼운 피아노, 잔잔한 스트링, 쉐이커, 소프트 퍼커션
* **보컬**: 맑고 따뜻한 여성 보컬 (원곡 "가을 그리고 차 한잔"의 서정 톤 계승), 코러스에서 하모니
* **분위기**: 설렘, 풋풋함, 봄바람, 두 손 맞잡고 걷는 산책

## 2. 사용 코드 (Chord Dictionary)

| 코드 | 운지 (6→1현) | 비고 |
| :-- | :-- | :-- |
| **C** | x 3 2 0 1 0 | 기본 |
| **G/B** | x 2 0 0 3 3 | 베이스 라인 하강용 |
| **Am** | x 0 2 2 1 0 | |
| **Em7** | 0 2 2 0 3 0 | 부드러운 전개 |
| **F (Fmaj7)** | x x 3 2 1 0 | 바레 없이 쉬운 F |
| **C/E** | 0 3 2 0 1 0 | 베이스 라인 |
| **Dm7** | x x 0 2 1 1 | |
| **G** | 3 2 0 0 0 3 | |
| **Gsus4** | 3 3 0 0 1 3 | 코러스 전 긴장 |
| **Em** | 0 2 2 0 0 0 | |
| **C7** | x 3 2 3 1 0 | 마지막 여운 |

**주법**: 인트로·벌스 = 핑거피킹 8비트 아르페지오 (엄지 베이스 → 검·중·약 순환), 코러스 = 다운-업 스트로크 `↓ ↓↑ ↑↓↑` (밝게 열기), 브릿지 = 약하게 뮤트 스트로크 후 점점 크레셴도.
