# 🖋️ 파이튼 문학 출판 연계 시스템
## (Phaeton Literary Publishing Architecture & Pipeline)

> **"국립 도서관은 인류 보편의 공공 성소로 지키고, 파이튼의 문학은 살아 숨 쉬는 블로그를 본진 삼아 순수한 문학적 가치로서 세상과 호흡한다."**  
> — 키아노스 국왕 **파이튼 (Python) 님**의 국정 철학

---

## 1. 시스템 구축 배경 및 국정 철학

1. **국립 인류문명사 대도서관의 공공성(천하위공) 확립**:
   - 국립 대도서관은 전 인류의 수천 년 지혜를 보존하는 공공 보고로서, 특정 개인이나 통치자의 인위적인 '특별서고' 편성을 전면 배제합니다.
2. **순수 문학적 가치로서의 독자적 보존**:
   - 파이튼 님의 작품(시, 수필, 팝송 스토리텔링)은 권력이나 관료적 특혜가 아닌, **독자들과 직접 교감하는 순수 문학적 가치**로서 다루어집니다.
3. **네이버 블로그 기반 출판 원본 금고 및 출판 파이프라인**:
   - 네이버 공식 블로그 **『파이튼의 문학산책』**(`https://blog.naver.com/invision`)을 출판 원본 금고로 지정하고,
   - 향후 단행본 종이책 및 전자책 출판 시행이 가시화될 때를 대비하여 원클릭으로 최신 원고를 수집·분류·출판 조판하는 시스템을 구축했습니다.

## 3. 한컴오피스 2024 & 출판 인쇄 표준 규격

- **글꼴(Font)**: **한컴 윤고딕 740** (출판 가독성 최우선 명조/고딕 조화 서체)
- **글자 크기(Font Size)**: 본문 **11pt** (`height="1100"`)
- **줄 간격(Line Spacing)**: **160%** (`lineSpacing type="PERCENT" value="160"`)
- **여백 규격**: 위 20mm, 아래 15mm, 좌(안쪽) 20mm, 우(바깥쪽) 15mm, 머리말 10mm

## 4. 파일 및 디렉터리 구성

```
파이튼_문학_출판연계시스템/
 ├─ 🚀 동기화_및_원고컴파일.bat          # [원클릭 실행] 네이버 블로그 최신글 수집 및 3대 도서 조판 갱신
 ├─ 🏛️ 키아노스_파이튼문학_출판관제실.url   # [Edge 바로가기] 출판 관제실 웹 대시보드 열기
 ├─ 🌐 파이튼_문학_출판관제실.html       # 출판 기획 현황 및 도서별 미리보기 웹 대시보드
 ├─ ⚙️ publish_engine.py                # 네이버 RSS 수집, 텍스트 정제, 마크다운/HTML 조판 엔진
 ├─ 📋 series_plan.json                 # 3대 시리즈 도서 기획 정의서
 ├─ 📊 latest_publish_summary.json     # 최신 컴파일 결과 및 수록 통계
 └─ 📁 출판_원고_보관소/                 # 최종 완성형 출판 원고 저장소
      ├─ 제01권_파이튼의 팝송 스토리텔링_출판원고.md
      ├─ 제01권_파이튼의 팝송 스토리텔링_조판미리보기.html
      ├─ 제02권_가을 그리고 차 한잔_출판원고.md
      ├─ 제02권_가을 그리고 차 한잔_조판미리보기.html
      ├─ 제03권_사색의 숲에서 길을 묻다_출판원고.md
      └─ 제03권_사색의 숲에서 길을 묻다_조판미리보기.html
```

## 5. 향후 출판 시행 절차 (Publishing Workflow)

1. **블로그 집필**: 네이버 블로그 『파이튼의 문학산책』에 자유롭게 글 작성 및 발행.
2. **원클릭 동기화**: `동기화_및_원고컴파일.bat` 실행 ➔ 수초 내에 3대 도서 원고 자동 업데이트.
3. **조판 검토**: `파이튼_문학_출판관제실.html`을 열어 e-Book 레이아웃 및 목차 점검.
4. **출간 진행**: 한컴오피스 2024로 복사하여 정식 HWPX 출판 원고 생성 또는 출판사/POD(부크크, 교보 등)로 직송.
5. **국립 도서관 배가**: 정식 도서 출간 시 [세계 문학관] 한국 문학 일반 서가에 품격 있게 배치.
